# Estudio Jurídico Griffo & Asociados

Sitio web institucional de una sola página (HTML + CSS + JS, sin dependencias ni compilación).

- `index.html`: sitio completo. Las tipografías se cargan desde Google Fonts.

## Publicación

Copiar `index.html` a la raíz pública del sitio (por ejemplo `htdocs/<dominio>/` en CloudPanel).
